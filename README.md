# X（Twitter）关注列表智能清理 Prompt

这个提示词用于分析 X 账号的「正在关注（Following）」列表，找出可能需要取关的低质量账号。它要求助手根据可观察的证据评分，先展示候选名单，再由你确认取关操作。

## 使用方法

1. 打开 [提示词文件](./x-following-cleanup-prompt.md)，复制全文。
2. 将提示词交给具备浏览器操作能力、且能够访问你当前 X 账号的 AI 助手。
3. 查看分析报告和候选名单，只批准你确认要取关的账号。

## 主要原则

- 综合活跃度、账号资料、内容质量和相关性等信号判断；无法核实的信息标记为「未知」。
- 优先保留有价值的信息源、专业人士、熟人和无法判断内容的私密账号。
- 每批最多处理 20 个账号；遇到平台限制、验证码或异常时暂停。

完整的评分标准、保护机制和执行流程见[提示词文件](./x-following-cleanup-prompt.md)。
